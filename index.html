GETTING STARTED

Setup guide.

Everything you need for your first connection.

01

Use a supported browser

Use Google Chrome or Microsoft Edge on a computer, or Chrome on Android. Web Bluetooth is not supported by standard Safari on iPhone. Open this site via HTTPS or localhost.

02

Connect to your clock

Turn the clock on, close other apps connected to it, select Connect clock, then choose the device beginning with NRF_.

03

Try a safe command

Once connected, try Sync date & time. Use Clock mode to restore the built-in updating display, or Calendar mode for its calendar.

04

Send your first image

Open Display studio, verify the screen dimensions and colour mode, review the preview, and select Send to clock. Give the e-paper display time to refresh.

About compatibility

This app targets the observable BLE protocol used by XLY95's original configuration site. The hardware variant has not yet been physically tested. All commands are configuration/display commands; there is no firmware flashing or device erasure.

Device sizes from the original JavaScript include 122 × 250, 400 × 300 and 800 × 480. The 400 × 300 setting is an educated guess for the photographed clock and should be verified in the original site.

For source code and deployment steps, see the included README.
